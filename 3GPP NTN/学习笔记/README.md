# NTN 学习笔记

本目录把第三代合作伙伴计划（3rd Generation Partnership Project，3GPP）的非地面网络（Non-Terrestrial Network，NTN）技术报告、相关新空口（New Radio，NR）规范、轨道与传播资料组织成一条连续知识链。内容既可以按六篇单独查阅，也可以通过合订版连续阅读。

合订版按六篇的输入/输出接口重排为一个连续文档，统一封面、总目录、来源状态说明和篇章过渡；六篇单稿仍是模块化维护入口。修改任一单篇后，应同步重新生成合订版，避免两套内容分叉。

全文主线为：

\[
\text{系统与场景}
\rightarrow
\text{轨道、时间与几何}
\rightarrow
\text{天线、波束与覆盖}
\rightarrow
\text{传播损耗与信道}
\rightarrow
\text{空口与协议适配}
\rightarrow

\]

标准 Clause、Table、Figure 和 Equation 只用于来源定位，不用于切割阅读结构。各篇只完整定义自己的核心对象，相邻篇通过稳定的输入/输出接口衔接。

## 使用约定

- Markdown 是内容源，PDF 与 Markdown 同名并从 Markdown 统一生成；合订版文件使用 `00_` 前缀，仅表示总册入口。
- 单篇修改日期记录在 YAML 的 `updated` 字段和 Git 历史中，文件名不加入日期或修订号。
- 英文简称第一次出现时给出英文全称和中文含义；公式使用标准 LaTeX，避免依赖冷僻 Unicode 数学字形。
- 绝对传播时延与局部超额时延、公共/差分/残余多普勒、路径损耗与天线增益分别核算，避免重复计数。
- 技术报告（Technical Report，TR）的研究问题、候选方案和进一步研究项，与技术规范（Technical Specification，TS）中的规范机制明确区分；工程解释与推导不写成标准强制结论。
