\[
\text{系统与场景}
\rightarrow
\text{轨道、时间与几何}
\rightarrow
\text{天线、波束与覆盖}
\rightarrow
\text{传播与信道}
\rightarrow
\text{空口与协议适配}
\rightarrow
\text{链路、系统与多星仿真}.

## 使用约定

- Markdown 是内容源；PDF 与 Markdown 同名，并从 Markdown 统一生成。
- 修改日期记录在 YAML 的 `updated` 字段和 Git 历史中；文件名不加入日期或笔记修订号。
- 公式中的绝对传播时延与局部超额时延、公共/差分/残余多普勒、路径损耗与天线增益分别核算，避免重复计数。
